## Part 6: Runtime Experiment

This program tests the running times of our four greedy algorithms from Part 1.

To run the experiment, use:

```
python benchmark_part6.py
```

The program generates random sets of 100, 1,000, 10,000, and 100,000 jobs. Each algorithm runs 10 times for each input size, and the median execution time is recorded.

The results are saved in `part6_results.csv`.
